# 카드 매칭 게임
***1~8의 숫자가 각각 두 장씩 들어있는 카드 16장의 짝을 맞추는 게임***

## 실행 방법
1. 뒤집을 두 카드의 위치를 "행 열" 형식의 정수로 한 쌍씩 입력한다. (예: 1 2)
2. 올바르게 입력했을 때, 해당 위치의 카드가 뒤집히고 숫자를 확인한다.
3. 짝을 맞췄을 경우, 다음 턴으로 넘어간다.
4. 짝이 맞지 않을 경우, 숫자를 확인한 후에 키보드에 아무키나 입력하면 카드가 다시 뒤집히고 다음 턴으로 넘어간다.
5. 모든 카드의 짝을 맞췄을 경우, 게임이 종료되고 시도 횟수가 출력된다.
